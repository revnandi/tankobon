# Theme sources and licenses

Tankobon's themes adapt a small subset of colors from the projects below. Theme names belong to their respective projects.

| Theme family | Source | License |
| :--- | :--- | :--- |
| Atom One | [Atom](https://github.com/atom/atom) | MIT |
| Ayu | [Ayu Theme](https://github.com/ayu-theme) | MIT |
| Catppuccin | [Catppuccin](https://github.com/catppuccin/catppuccin) | MIT |
| Dracula and Alucard | [Dracula](https://github.com/dracula/dracula-theme) | MIT |
| Everforest | [Everforest](https://github.com/sainnhe/everforest) | MIT |
| Gruvbox | [Gruvbox](https://github.com/morhetz/gruvbox) | MIT |
| Nord | [Nord](https://github.com/nordtheme/nord) | MIT |
| Rose Pine | [Rose Pine](https://github.com/rose-pine/rose-pine-theme) | MIT |
| Tokyo Night | [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme) | MIT |

Night Owl, Night Owlish Light, GitHub Light Default, and Lovelace were adapted from the [iTerm2 Color Schemes collection](https://github.com/mbadolato/iTerm2-Color-Schemes). The collection is MIT licensed, but its license notes that individual themes remain under their original authors' copyrights and licenses.
